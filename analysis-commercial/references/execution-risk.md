# 执行风险

研究做错亏小钱，仓位做错亏大钱。先组合，再期望值，再缺口，再容量，再事件，再退出。

## 1R

`1R` = 该笔计划亏损额（含预估费用），不是名义市值。
开放风险 = 战术袖全部未平仓计划 `1R` 之和。
主题热量 = 同一主题战术 `1R` 之和。主题是相关代理，禁止编造相关系数。

限额：

- 多头单笔 `1R ≤ 1%` 净资产
- 空头单笔 `1R ≤ 0.5%` 净资产
- 战术袖总开放风险 `≤ 6%`
- 单主题战术热量 `≤ 2.5%`
- 战术空头合计 `≤ 2%`
- 宽基袖不计入主题热量，只在报告里披露重叠 beta

超限 → `不交易（组合约束）`。写明需要释放多少 `1R` 才能重评。

## 目标

目标必须有独立依据，三选一：

- `technical`：测量摆动、前高、通道
- `valuation_reversion`：回到自身历史分位
- `event_reprice`：事件对盈利或倍数的可核对重估

禁止：把目标画成“止损距离 × 2”。脚本在 `target_basis` 缺失或为 `reverse_rr` 时拒绝。

无本地平仓日志时，胜率字段必须是 `未校准估计`。可以给盈亏平衡胜率：`1 / (1 + 费用后盈亏比)`。禁止写“该类形态历史胜率 xx%”。

## 止损与缺口

- 先定论点失效价，再与 `1.5 × ATR(20)` 比：止损距离更小则拒绝
- 缺口幅度用该标的历史分位，建议 P95；样本不足用行业代理并标注
- 做多用向下缺口，做空用向上缺口
- 仓位 = min(计划风险约束, 缺口穿透后亏损 ≤ 2% 净资产)

不要靠“把止损设更近”来制造 1% 风险。那只会提高被扫掉的概率，缺口亏损不会变小。

## 流动性

出清天数 = 仓位金额 / (ADV × 参与率)

- 多头默认参与率 `10%`
- 空头默认参与率 `5%`
- `>1` 天警告，`>3` 天禁止开仓

拟开仓金额本身若已超过容量，即使把止损收紧也仍禁止。

## 做空附加

- 借券费未知 → 脚本失败
- `short_interest_pct ≥ 20` 或 `days_to_cover ≥ 5` → 逼空拒绝
- 禁止杠杆 / 反向 ETF / 期权放大

## 费用

报告使用脚本输出的费用后盈亏比。默认值可被输入覆盖：

| 市场 | 默认 |
|---|---|
| US | 佣金 0.05% 双边 + 5bp 滑点 |
| HK | 佣金 0.08% 双边 + 印花 0.10% 卖出 + 8bp 滑点 |
| CN | 佣金 0.025% 双边 + 印花 0.05% 卖出 + 8bp 滑点 |

费用计入计划亏损和盈亏比，不要在心算里忽略。
