# 宽基长期配置

标普 500、纳斯达克 100 及对应 ETF（VOO、SPY、QQQ 等）走这一条，不走个股波段动作。

## 默认

有工作收入、期限 ≥10 年、应急金够用、不用杠杆：默认 **开始或继续分批配置**。估值只调节速度。

| 估值与环境 | 节奏 |
|---|---|
| 低估或中位附近 | 可加速，仍分批 |
| 偏高 | 维持正常定投，不一次买完 |
| 估值、情绪、杠杆同时处历史极值 | 才讨论 `暂不配置`，且红队用最高举证 |
| 不知现有美股占比 | `信息不足` |

`暂不配置` 是最贵建议。单独的高估值、单独的坏新闻、单独的波段回撤，都不够。

## 看什么

- 指数远期盈利与过去十年估值分位
- 实际利率与风险溢价，不是名义利率口号
- 成分股集中度：集中度高要在报告里披露，它不是自动清仓理由
- 再平衡是纪律，不是择时信号
- 用户已有 QQQ / VOO 仓位属于宽基袖，不计入战术主题热量

## 输出

只能用：

- `开始或继续分批配置`
- `等待或再平衡`
- `暂不配置`
- `信息不足`

禁止：

- 把宽基结论写成某只个股 `可执行`
- 用 1–6 个月波段模型决定整个十年计划
- 建议用杠杆或反向 ETF 对冲长期仓
- 因为战术半导体票太热，就让用户卖掉纳指长期仓

宽基若被明确要求做 1–6 个月波段，改走战术袖，并单独计算 1R，不得与长期定投混写。
