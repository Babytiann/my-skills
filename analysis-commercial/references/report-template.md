# 报告模板

每次输出都用这个结构。数字必须来自脚本或账本，禁止另写一套。

```markdown
# 报告头
- 日期（系统确认）：
- 数据截止：
- 模式：全量建档 / 快速更新
- 袖：战术波段 / 宽基长期
- 授权：现货多 / 现货空 / 无杠杆
- 净资产与币种：
- 已有持仓（标的 / 方向 / 1R / 主题 / sleeve）：
- 未覆盖项：

# 实体与问题
- 标的：
- 用户问题：
- 持仓状态：无仓 / 有仓

# 证据账本摘要
- A 级主张与 origin_cluster：
- 闸门：PASS / FAIL
- 闸门缺口：
- 同源去重说明：

# 三层与残差
- 相对大盘 / 相对行业：
- 宏观：
- 行业（子行业）：
- 公司：
- 流动性 / 预期差 / 边际变化：

# 因果
- 主张：
- 证据档：已验证事实 / 强证据 / 弱证据 / 传闻
- 因果档：高度支持 / 条件支持 / 证据不足 / 不支持
- 背景脆弱性 / 直接触发 / 放大机制：
- 已处理的替代解释：
- 对手方为什么在卖：

# 红队
- 最强攻击：
- 是否推翻准出：

# 交易或配置
## 若战术袖
- 动作：可执行 / 等待验证 / 不交易 / 不交易（组合约束） / 继续持有 / 减仓 / 清仓 / 已触发退出
- 方向：
- 入场 / 失效 / 目标 / 目标依据 / 期限 / 时间止损：
- trade_math.py 原文：
- 事件政策：
- 退出树：

## 若宽基袖
- 动作：开始或继续分批配置 / 等待或再平衡 / 暂不配置 / 信息不足
- 节奏：加速 / 正常定投 / 减速
- 与战术袖的隔离说明：

# 下次检查
- 日期：
- 触发：哪些变量变了必须重跑
```

## 平仓复盘 schema

这是胜率校准的唯一来源。没有这些日志，禁止引用历史胜率。

```json
{
  "ticker": "",
  "opened_at": "",
  "closed_at": "",
  "direction": "long",
  "planned_r": 0,
  "realized_r": 0,
  "exit_reason": "stop|target|time|event|manual",
  "thesis_correct": true,
  "excess_vs_benchmark": "",
  "notes": ""
}
```

复盘写入本地 `dossiers/_journal/closes.jsonl`。没有该文件时，报告必须出现 `未校准估计`。
