# Composer 参考稿：精细度案例

两份参考稿用来校准“一个局部要定多少东西”，不提供样式和数值。动手前选与本次改动结构最接近的一例，在浏览器中按锚点查看；没有相近结构时，只读文末“通用方法”和“不迁移”。

## 怎么看

- 直接打开本地文件并跳到锚点，视口宽 1280。v3 窄于 1100、v6 窄于 1020 时，旁注会折到画面下方。
- 画板内容由脚本注入，选中底块、贴合高度和 hover 定位要等脚本与字体加载完成才出现；截图前稍等，不要只读源码。
- 两份稿默认暗色，用页首按钮切换明暗。目标项目是浅色时，切到浅色再对照。
- 浏览器不可用时，读下面列出的选择器和函数，不整份读源码。行号对应归档版本，只作辅助定位。

每例分两层：**方案给定**是业务文档已经写定的规则，只看画面怎样如实落地，不当作通用标准；**设计补的**是设计稿自己定下的参数与关系，可迁移的方法只从这一层提炼。

## 1. 菜单与检索结果

画面：[v3 `/` 命令](sources/composer-attachments-menu-v3.html#board-slash)、[`@` 默认](sources/composer-attachments-menu-v3.html#board-at)、[`@` 搜索](sources/composer-attachments-menu-v3.html#board-at-search)、[`$` 技能](sources/composer-attachments-menu-v3.html#board-dollar)、[无匹配](sources/composer-attachments-menu-v3.html#board-empty)。

- **方案给定**（PR 9）：标题大写、描述占比、来源靠右、选中条滑动、`@` 默认只出两行、文件名在前地址在后、搜不到时收成一行。
- **设计补的：**
  - 对齐：行外边距 6 加内边距 10，等于分组名左边距 16，也等于输入框左右内边距，菜单文字和输入文字落在同一条竖线上；菜单圆角复用输入框圆角。
  - 主次：分组名、命令名、描述都是 13px，靠字重 500/400、墨色深浅和 0.78 透明度分层；来源 11px 靠右。选中只提亮名称和图标、让次要文字恢复不透明，不改字号，不加颜色。
  - 宽度：命令行的描述最多占剩余宽度的 80%，名字不让位；文件行的名字完整显示，路径占满剩余宽度并在尾部省略。
  - 高度三形态：内容少时贴合，去掉遮罩、收小内边距；超出上限时滚动，上下各一层渐隐遮罩，遮罩高度等于列表内边距，静止时不压内容；无匹配时收成一行纯文字，与分组名同一档。静态画板把 `/` 菜单预滚到中段，让上下遮罩和被标注的行同时可见。
  - 选中底块：来自绝对定位的 `.row-hl`，由脚本量好位置后显示；`.row.is-on` 只改字色。只照抄 `.is-on` 会丢掉底块；不做滑动时，把底块直接写在选中态样式上。
- **源码：** `.pop` `.pop-list` `.row-hl` `.row-inner` `.row-name` `.row-desc` `.row-origin` `.row.is-file` `.pop.is-hug` `.pop.is-empty`（v3:358-502）；`renderMenu` `bindGlide` `paint`（v3:1092-1164）；`hugPops` 与预滚（v3:1455-1494）；旁注（v3:1409-1432）。

## 2. 文字与对象混排

画面：[v6 类型总表](sources/composer-presentation-v6.html#board-kinds)、[细节](sources/composer-presentation-v6.html#board-detail)；附件栏与队头见 [v3 输入框](sources/composer-attachments-menu-v3.html#board-composer)。

- **方案给定**（设计方案第 7 节、PR 9）：命令、技能、文件、实体引用各有指定色系，图片色由内容决定；附件栏钉在 carry 下、格子正方形、折行不横滚、最多八张、点 X 连正文胶囊一起删。
- **设计补的：**
  - 一个视觉变量只表示一件事：颜色表示类型，图标表示来源或子类，文字表示具体是哪一个。有专属图标就覆盖默认图标，颜色不跟着变；四种队头签用同一套中性色，靠文字区分。
  - 同类对象的底、边、字三种颜色用同一个公式从输入框底色混出，明暗主题各定比例。
  - 截断与换行：标签超过 16em 尾部省略；气泡里整颗封顶，上限等于最窄栏时的气泡内容宽，宽栏窄栏同长；行末放不下整颗换行，不挤扁；带参命令省参数尾部，命令名不让位；只有展开编辑态可以超宽。
  - 附件格高约等于两行正文行高；悬停才出现 X，气泡里只读、不出 X。
  - 正文超过 20 行收起，留“查看消息”入口。
- **源码：** 五类填色 `.tone-*`（v6:467-520）；`.chip` 与上限，推导写在注释里（v6:523-673，见 v6:591）；`.carry-pill`（v6:694-733）；细节画板与旁注（v6:1951-2083）；长消息（v6:349-404、2074-2095）。附件栏 `.composer-carry-row` `.composer-attach-row` `.att` `.att-x`（v3:610-720），数据与渲染（v3:1221-1399）。
- **注意：** v3 旁注写“超过约 9 行正文自己滚”，示例正文实际不到 9 行，滚动只停留在旁注里。新稿要让数据真正超过上限。

## 3. 浮层层级

画面：[v6 浮层规格](sources/composer-presentation-v6.html#board-hover-spec)、[气泡上的 hover](sources/composer-presentation-v6.html#board-hv-bubble)、[输入框上的 hover](sources/composer-presentation-v6.html#board-hv-composer)、[文件浮窗](sources/composer-presentation-v6.html#board-float)、[批注浮窗](sources/composer-presentation-v6.html#board-float-cmt)。

- **方案给定**（设计方案第 7 节、PR 8）：hover 速览、双击开浮窗；一套 hover 不按类型分形，三个槽有就填；文件浮窗居中压在会话上；批注浮窗在输入框侧可编辑可删，历史气泡侧只读。
- **设计补的：**
  - 三级表面：贴着输入框的菜单、锚在对象上的 hover、居中的浮窗，各用一档阴影；浮窗背后加模糊遮罩，背后的对象只剩轮廓，所以浮窗顶栏自己写身份。
  - hover 宽等于输入框外壳宽的 80%；高度封顶后正文自己滚，身份行不跟着滚。
  - 三槽：身份 14/600；次级信息 12 或 11 号弱色，路径用等宽字；正文 13/1.7 次级墨色。只有名字时不套卡加粗，收成一条。
  - 浮层打开时，触发它的 chip 或队头签同时进入打开态（描边）。
  - 溢出提示：批注浮窗滚动后，标题栏才出现分隔线；文件浮窗的横向滑轨默认隐藏，指针接近下沿才浮现。
  - 批注每段有行数预算：标题一行、来源一行、正文三行、评语两行；hover 最多摊 5 条，其余进浮窗。
- **源码：** 阴影 `--shadow-composer` `--shadow-overlay` `--shadow-float`（v6:53-59、88-94）；`--hv-width` 推导（v6:20-21）；`.hv` `.hv-name` `.hv-meta` `.hv-body`（v6:905-1097）；`placeHover`（v6:1863）；`buildHoverSpec`（v6:2098-2149）；`.scrim` `.float`（v6:1274-1431）；`buildFloat` `buildFloatCmt`（v6:2197-2402）；滚动分隔线（v6:1101、2562）。
- **注意：** 文件浮窗的部分按钮是展示用的 span，浮窗预先展开；v3 的附件 X 也只有旁注。只有旁注、没有实现的交互，不作为交互标准。

## 4. 标注层

字母 pin 加“条件 → 变化”旁注加箭头，旁注放在画面右侧，窄视口折到下方：v3 `.spec-notes`（v3:722-784），v6 `.spec`（v6:802-902）。

## 通用方法

从“设计补的”提炼，代入目标项目的基准值：

- 尺寸写成关系：浮层宽 = 宿主外壳宽 × 比例；截断上限 = 最窄容器的内容宽；附件高 = N 倍正文行高；遮罩高 = 列表内边距；浮层圆角复用宿主圆角。
- 浮层文字与宿主输入文字共用一条左对齐线。
- 先把目标项目的墨色、边框、表面层级对应到语义（主、次、弱文字；弱、强边；底、浮层、井），再派生状态色和类型色。
- 少用字号档，主次靠字重、墨色和透明度。
- 列表和浮层都要有贴合、滚动、空结果三种高度，以及滚动时的提示。
- 截断前先定谁让位、保留什么、放不下时换成什么形态。

## 不迁移

- 评审外壳：600 字重标题、大写画板标签、毛玻璃粘顶页头、明暗切换坞。评审层按 SKILL.md 的细线条标题和克制用色处理。
- 默认暗色，以及 Inter、Noto Sans SC、JetBrains Mono 和 Google Fonts。
- 全部具体数值：13px、7.2px、10.8px、16em、261、483、20 行、0.78 等，只在本例成立。
- Composer 业务规则，包括类型配色和 PR 8、PR 9 的条目与阈值。
