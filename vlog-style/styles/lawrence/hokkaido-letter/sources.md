## 怎么测的

- 画面：TransNetV2 + PySceneDetect 找剪辑点（150 个剪辑点、151 个镜头，两路一致 135 个，没有被否掉的）；LK 光流测运动；Lab look card（150 个镜头关键帧，遮掉字幕带和 OCR 框）；Apple Vision OCR（每秒 4 帧，458 条文字轨）。
- 声音：ebur128 响度；beat_this 拍点，librosa 交叉核对（80.0 / 80.7 BPM，一致）。
- 用 `--no-asr` 跑，没有跑 whisper：烧录字幕覆盖了全部旁白，人声区间按字幕时间算。
- **speech_share 0.548 偏高。** OCR 把歌词段的几行（文字轨 193、242、248、399、405，约 20 s）当成了字幕，这段时间也算进了人声。去掉以后，真正的旁白占比约 0.48：**存疑**。照片插入段（187.5–194.0 s）的居中双语字幕带底板，可能是引用的台词而不是旁白，也算进了人声。
- 判读：三个子 agent 依次完成，主会话核对。判读材料有 10 张总览图、2 张推拉对照图和 64 条事件条（转场候选、抽样硬切、文字出入）。结果填进 labels.json，拒收 0 条，未核实 0 条。推拉看不准的，取 10%、90% 两帧，比较上半和下半的缩放。
